# Tech Interview English

Vocabulário e frases essenciais para entrevistas de emprego na área de tecnologia.

---

## Falar sobre experiência

| Português | Inglês |
|---|---|
| Trabalhei com... | I worked with / I've been working with... |
| Fui responsável por... | I was responsible for... |
| Liderei um time de... | I led a team of... |
| Contribuí para... | I contributed to... |
| Implementei... | I implemented / I built... |
| Melhorei o desempenho em... | I improved performance by... |
| Reduzi o tempo de... | I reduced the time for... |

---

## Falar sobre habilidades técnicas

- I'm proficient in / I'm comfortable with...
- I have hands-on experience with...
- I've been working with [tecnologia] for [X] years.
- I'm currently learning / exploring...
- I'm familiar with [tecnologia], though I haven't used it professionally yet.

---

## Responder perguntas comportamentais (STAR method)

**Situação:** "So, back when I was at [empresa]..."
**Tarefa:** "My task was to..."
**Ação:** "What I did was... / I decided to..."
**Resultado:** "As a result... / In the end..."

Frases úteis:
- "That's a great question. Let me think for a second..."
- "To give you some context..."
- "The outcome was..."
- "Looking back, I would have..."
- "One thing I learned from that was..."

---

## Defender decisões técnicas

- "I chose [X] over [Y] because..."
- "The main trade-off was..."
- "Given the constraints at the time, I decided to..."
- "In hindsight, I might have..."
- "The bottleneck was... so I..."
- "We needed to balance [X] and [Y]."
- "It was a trade-off between performance and simplicity."

---

## Vocabulário técnico frequente em entrevistas

| Termo | Como usar |
|---|---|
| scalability | "We needed to think about scalability from day one." |
| trade-off | "There's always a trade-off between speed and reliability." |
| bottleneck | "The bottleneck was the database layer." |
| latency | "We reduced latency by 40% using caching." |
| throughput | "The system handles 10k requests per second." |
| fault tolerance | "We designed it to be fault tolerant." |
| eventual consistency | "We opted for eventual consistency to improve availability." |
| idempotent | "The endpoint is idempotent, so retries are safe." |
| refactor | "We refactored the auth module to reduce complexity." |
| tech debt | "We had significant tech debt from the initial MVP." |
| deployment | "We deploy to production three times a week." |

---

## Pedir esclarecimento (sem parecer inseguro)

- "Just to make sure I understand — you're asking about...?"
- "Could you give me a bit more context on that?"
- "Do you mean [X] or [Y]?"
- "I want to make sure I'm answering the right question."

---

## Mostrar interesse na empresa

- "What does the onboarding look like for engineers?"
- "How does the team handle technical debt?"
- "What does a typical sprint look like?"
- "What's the biggest challenge the team is facing right now?"
- "How does the company approach work-life balance?"

## Erros comuns de brasileiros

| Errado | Certo |
|---|---|
| I work with Python since 3 years | I've been working with Python for 3 years |
| I have 27 years | I'm 27 years old |
| In the company where I worked... | At the company where I worked... |
| I make a system that... | I built a system that... |
| I am agree | I agree |
| Explain me | Explain to me / Could you explain... |
